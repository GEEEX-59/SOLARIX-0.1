# SOLARIX — PWA

Aplicación web progresiva (PWA) para cálculo y dimensionamiento solar.

## Publicar en GitHub Pages

1. Sube **todo el contenido de esta carpeta** a un repositorio de GitHub.
2. En el repositorio entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/ (root)`.
5. Guarda y abre la URL que GitHub Pages te proporcione.
6. En Android/Chrome usa **Instalar app** o **Añadir a pantalla de inicio**.

### Importante
La instalación PWA necesita HTTPS. GitHub Pages proporciona HTTPS automáticamente.

La información de los proyectos se guarda en `localStorage` del dispositivo/navegador. Si borras los datos del sitio, también se borra el historial local.
